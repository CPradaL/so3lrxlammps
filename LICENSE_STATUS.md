# Licensing status

No public redistribution license is asserted by this technical release
candidate. The SO3LR authors must approve the source license, third-party
notices, model-weight license, checkpoint redistribution terms, and use of
LAMMPS-derived integration interfaces before a public GitHub release.

The package distributes one model, SO3LR (`models/so3lr.so3lr`).
`.gitignore` keeps every other `.so3lr` file out of the repository. Do not
commit other converted models unless the SO3LR authors explicitly approve
their redistribution.
